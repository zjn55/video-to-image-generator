# 视频转图片生成工具（桌面版）

一个**完全离线**的视频截帧、图片编辑与精灵图生成工具。从视频中按间隔截取所有帧 → 选择需要的帧 → 调整顺序并分组 → 按分组导出为 PNG 图片或精灵图（Sprite Sheet）；内置功能完整的图片编辑器。所有处理都在本机完成，**不联网、不上传**，隐私安全。

## 运行方式

双击 `dist\视频转图片生成工具\视频转图片生成工具.exe` 即可运行（界面与网页操作一致）。exe 依赖同目录的 `_internal` 文件夹，分发/拷贝时请整体移动整个文件夹。

- 格式转换（含 OGV/MOV/AVI）由应用内**内置的 ffmpeg** 完成，转好的文件自动保存到系统「下载」目录。

## 功能特性

### 1. 上传视频
- 点击或拖拽上传本地视频（MP4 / WebM / MOV 等浏览器可播放格式）
- 也可直接上传图片，跳过截帧，直接进入图片编辑器

### 2. 截取帧并选择
- 自定义截帧间隔（秒），自动按间隔截取所有帧
- 时间区间双滑块，只截取视频任意一段区间的帧
- 可手动添加任意一帧；网格展示缩略图，支持全选、反选、点击切换选中状态
- 可提取视频音轨（受时间区间影响）

### 3. 调整帧顺序与分组
- 拖拽调整顺序（缩略图跟随鼠标 + 插入线提示落点）
- 拖到「新建分组」区域自动建组；分组标题双击内联重命名
- 回到第二步勾选/取消帧后，本步骤自动同步

### 4. 导出设置
- **逐个导出图片**：按分组导出为独立文件夹，打包 ZIP 下载
- **生成精灵图**：每个分组独立设置列数、行数、帧尺寸、间距、背景，按分组生成并打包

### 5. 视频格式转换
- 上传视频后即可转换格式，支持 **MP4 / WebM / OGV(Theora) / MOV / AVI**
- 转换调用内置 ffmpeg，本地处理、保真、不上传；结果保存到「下载」目录

### 6. 内置图片编辑器
- 旋转 / 翻转、裁剪、缩放尺寸
- 亮度、对比度、饱和度（每项带重置，可拖动或输入数值）、像素化
- 画笔（粗细可拖动或输入，撤销/重做）
- 局部调整：矩形 / 椭圆 / 手动套索 / 背景色框选，对选定区域应用任意效果
- 去水印、只保留选区（抠出对象做透明背景角色帧）、填充色
- 选区管理：多选区合并（并/交/差）、树状容器、拖动排序
- 箭头、文字：可拖动、缩放、旋转、单独删除；文字为独立对象，可编辑内容、字号与颜色
- 撤销 / 重做；选中对象按 Backspace / Delete 删除

## 技术说明

- 桌面应用基于 **pywebview**（使用系统 WebView2 内核运行同一套前端界面），Python 端直接调用内置 **ffmpeg** 做格式转换
- 前端：原生 HTML / CSS / JavaScript，无框架、无构建步骤
- 全部处理在本机完成，不产生任何网络请求

## 重新打包（修改后更新 exe）

1. 修改代码：前端改 `图片生成器.html` / `js\*.js` / `css\style.css`；后端（转换参数等）改 `desktop_app.py`。
2. 运行 **`python build.py`** 自动重新打包（约 1 分钟），新 exe 覆盖到 `dist\视频转图片生成工具\`。
3. 运行新 exe 即可。

> **在任何电脑上打包**：`build.py` 以脚本自身所在目录为基准，不写死某台机器的路径，克隆仓库到任意电脑（需装 Python 与 `pip install pyinstaller pywebview`）后直接 `python build.py` 即可。
> **ffmpeg 可选**：仓库未包含体积较大的 `ffmpeg/` 目录。若本地有 `ffmpeg/ffmpeg.exe`，`build.py` 会自动把它打包进去（提供 OGV/MOV/AVI 等格式转换）；没有也能正常打包，只是格式转换不可用（页面会提示“未找到内置 ffmpeg”）。
> 打包会忽略 `dist/`、`build/`、`ffmpeg/` 等体积大的本地文件（见 `.gitignore`），GitHub 仓库只含源码与打包脚本。

## 兼容性

- 平台：Windows（需系统自带 WebView2，Win10/11 一般已内置）
- 视频格式：取决于浏览器内核，一般支持 MP4 / WebM / MOV
- 格式转换：内置 ffmpeg 支持 MP4 / WebM / OGV / MOV / AVI
