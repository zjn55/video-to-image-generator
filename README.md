# 图片生成器 · 视频截帧与精灵图工具

一个**纯前端、完全离线**运行的视频帧处理网页工具。从视频中按间隔截取所有帧 → 选择需要的帧 → 调整帧顺序并分组 → 按分组导出为 PNG 图片或精灵图（Sprite Sheet）。所有处理都在本地浏览器完成，**不会把任何视频或图片上传到服务器**，隐私安全。

## 功能特性

### 1. 上传视频
- 支持点击或拖拽上传本地视频（MP4 / WebM / MOV 等浏览器可播放格式）
- 视频解析全程本地完成，不上传

### 2. 截取帧并选择
- 自定义截帧间隔（秒），自动按间隔截取所有帧
- 时间区间双滑块，只截取视频任意一段区间的帧
- 可手动添加任意一帧（跳到特定时间点）
- 网格展示所有截帧缩略图，支持全选、反选、点击切换选中状态

### 3. 调整帧顺序与分组
- 选中帧按缩略图网格展示，可拖拽调整顺序（缩略图跟随鼠标 + 红色插入线提示落点）
- 拖到「新建分组」区域自动创建分组并放入
- 分组标题双击内联重命名
- 支持跨分组拖拽移动帧、删除分组（帧自动回到未分组）
- 回到第二步勾选/取消帧后，本步骤自动同步

### 4. 导出设置
- **逐个导出图片**：勾选要导出的分组，每个分组导出为一个独立文件夹，文件夹名默认取分组名，也可自定义前缀命名；打包成 ZIP 下载，解压后是按序号命名的图片
- **生成精灵图（Sprite Sheet）**：每个分组一个独立下拉框，头部勾选控制是否生成该分组的精灵图，展开可查看该分组的全部帧并设置它自己的生成约束
  - 每分组独立设置：列数、行数（0 为自动）、帧宽/帧高（0 为原尺寸）、间距、背景（透明/纯色）
  - 按分组预览并打包下载 ZIP

### 5. 内置图片编辑器
双击任意截帧（或从第二步进入）即可打开内置编辑器：
- 旋转 / 水平垂直翻转
- 裁剪（从当前编辑结果继续）
- 缩放尺寸（显示原始宽高；矩形 / 椭圆 / 逐像素选区都会随图片尺寸自动适配，保持一致）
- 亮度、对比度、饱和度调整，每项带重置按钮，可拖动也可直接输入数值
- 像素化效果
- 画笔：可调粗细（拖动或直接输入像素值），支持撤销 / 重做
- 局部调整：矩形框选 / 椭圆框选 / 手动套索 / 背景色框选，对选定区域应用任意效果
- 去水印、只保留选区（抠出对象做透明背景角色帧）
- 背景色选区：预览选中像素、按住 O 临时隐藏选区查看原图
- 填充色
- 箭头、文字：可拖动、缩放、旋转、单独删除；文字为独立对象（文字类），选中后可在「选择」面板内编辑内容、字号与颜色（所见即所得，无需画布光标）；选择面板为可折叠卡片列表式，属性条目每行独立，右侧带重置按钮
- 撤销 / 重做；选中对象按 Backspace / Delete 可删除

## 使用方法

直接用浏览器打开 `图片生成器.html` 即可，无需安装、无需网络。推荐使用 Chrome / Edge 等现代浏览器。

1. 第一步上传视频
2. 第二步设置截帧间隔，选择需要的帧
3. 第三步调整帧顺序、拖入分组
4. 第四步选择「逐个导出」或「生成精灵图」，点击导出下载

## 技术说明

- **纯前端实现**：原生 HTML / CSS / JavaScript，无任何框架、无构建步骤
- **离线运行**：ZIP 打包使用本地内置的 `vendor/jszip.js`，不依赖 CDN
- **本地处理**：视频解析、截帧、图片编辑、导出全部在浏览器内完成，数据不出本机
- **隐私安全**：不上传服务器、不产生网络请求

## 文件结构

```
图片生成器/
├── 图片生成器.html     # 入口页面（打开它即可使用）
├── css/
│   └── style.css       # 全部样式
├── js/
│   ├── app-core.js             # 核心工具 / 全局状态
│   ├── app-main.js             # 主流程（视频上传、截帧、分组、导出）
│   ├── app-editor-core.js      # 图片编辑器核心（绘制、选区区域模型、文字类）
│   ├── app-editor-adjust.js    # 亮度/对比度/饱和度、裁剪、缩放、像素化
│   ├── app-editor-region.js    # 选区管理
│   ├── app-editor-annotate.js  # 绘制标注（画笔/箭头/文字、选择属性）
│   └── app-editor-canvas.js    # 画布交互（创建对象、缩放平移）
└── vendor/
    └── jszip.js        # 离线 ZIP 打包库
```
